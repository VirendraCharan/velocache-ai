# VeloCache AI

A predictive caching middleware built with Spring Boot, Redis, and a Python/Scikit-Learn forecasting layer.

## A note on the traffic in this project

The requests hitting VeloCache AI aren't from real users, they're generated by a Python script I wrote (`simulator.py`) that fires requests on a schedule, mostly steady, with a repeating burst every so often to imitate a traffic spike. I built it this way because this is a solo project, there's no real user base to pull traffic from, and a script was the only practical way to actually exercise the caching and forecasting pipeline end to end. Even though the traffic itself is fake, what it proves is real: two separate tenants stayed correctly isolated in Redis under load, the rate limiter kicked in exactly where it should and the system kept recording traffic instead of silently dropping it, and the repeating pattern I designed actually showed up in Redis's stored data when I checked it independently, not just in console logs. That's the part I actually care about demonstrating, the system behaves correctly under realistic, structured load, even if that load didn't come from real people clicking around.
